# User Stories

## 1. User Registration
As a new user, I want to create an account using username, email, and password so that I can securely access the app.

## 2. User Login
As a registered user, I want to log in using my credentials so that I can access my account.

## 3. Home Screen
As a user, I want to view my habits on the home screen so that I can track my progress.

## 4. Detail Screen
As a user, I want to open a detail screen so that I can view more information about a habit.

## 5. Favorites
As a user, I want to save favorite items so that I can quickly access them later.

## 6. Local Storage
As a user, I want my data stored locally so that my information persists after closing the app.

## 7. API Integration
As a user, I want the app to fetch external data from APIs so that content stays updated.

## 8. Settings Screen
As a user, I want to customize app settings like themes and notifications.

## 9. Notifications
As a user, I want reminder notifications so that I stay consistent with my habits.
